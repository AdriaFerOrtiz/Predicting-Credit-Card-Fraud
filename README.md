# Predicting Credit Card Fraud

Machine Learning project focused on detecting fraudulent credit card transactions using classification algorithms.

## Project Objectives

- Exploratory Data Analysis (EDA).
- Data preprocessing and feature engineering.
- Machine Learning model comparison.
- Imbalanced classification techniques.
- Hyperparameter optimization.
- Model evaluation and fraud detection.

## Dataset

Predicting Credit Card Fraud - Kaggle.

Target variable: `is_fraud`

| Dataset | Rows | Columns |
|---|---:|---:|
| Train | 699,960 | 26 |
| Test | 299,984 | 25 |
| Sample Submission | 299,984 | 2 |

Original datasets are stored locally and are not included in this repository.

## Project Structure

- `data/`: Dataset files.
- `notebooks/`: Jupyter notebooks.
- `outputs/`: Generated outputs.
- `requirements.txt`: Project dependencies.
